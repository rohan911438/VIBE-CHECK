# Mental Health Tracker

A simple, client-side web application to help users get a quick snapshot of their current mental well-being through a short quiz.

## Description

This Mental Health Tracker is a lightweight, easy-to-use tool designed to provide a general assessment of a user's mental state. It asks a series of questions about common mental health indicators such as mood, sleep quality, anxiety, and energy levels. Based on the user's answers, it calculates a score and provides a corresponding recommendation.

This tool is for informational purposes only and is not a substitute for professional medical advice, diagnosis, or treatment.

## Features

*   **Interactive Quiz:** A 5-question quiz with multiple-choice answers.
*   **Instant Results:** Users receive immediate feedback after completing the quiz.
*   **Scored Assessment:** A simple scoring system provides a general indication of the user's mental state.
*   **Actionable Recommendations:** The results come with suggestions, from practicing self-care to seeking professional help.
*   **Responsive Design:** The interface is designed to work on different screen sizes.
*   **Client-Side Only:** The application runs entirely in the browser, ensuring user privacy as no data is sent to a server.

## How to Use

1.  Clone or download this repository.
2.  Open the `index.html` file in your web browser.
3.  Answer all the questions in the quiz.
4.  Click the "Submit" button to see your result.

## Technologies Used

*   **HTML:** For the structure and content of the web page.
*   **CSS:** For styling the application and making it visually appealing.
*   **JavaScript:** For the quiz logic, score calculation, and displaying the results.
