# Vibe Check: Mental Wellness Quiz

A modern, Gen Z-focused client-side web application designed to provide a quick and engaging snapshot of your current mental well-being through an interactive quiz.

## Description

"Vibe Check" is a lightweight, stylish, and easy-to-use tool that offers a general assessment of a user's mental state. It features a series of questions covering key mental health indicators such as mood, sleep quality, social connection, anxiety, and energy levels. Based on your responses, the app calculates a score and provides personalized, actionable recommendations.

**Disclaimer:** This tool is for informational purposes only and is not a substitute for professional medical advice, diagnosis, or treatment. If you are experiencing mental health difficulties, please seek help from a qualified professional.

## Features

*   **Personalized Welcome:** Start with a name input to personalize the experience.
*   **Engaging Quiz:** A 5-question interactive quiz with a modern, intuitive interface.
*   **Dynamic Design:** Features a black and blue dynamic color scheme, appealing to Gen Z aesthetics.
*   **Personalized Recommendations:** Provides tailored suggestions based on your quiz results, ranging from self-care tips to resources for professional help.
*   **Instant Feedback:** Receive immediate and clear feedback after completing the quiz.
*   **Client-Side Only:** The application runs entirely in the browser, ensuring user privacy as no data is sent to a server.
*   **Responsive Layout:** Optimized for seamless use across various devices and screen sizes.

## How to Use

1.  Clone or download this repository.
2.  Open the `index.html` file in your web browser.
3.  Answer all the questions in the quiz.
4.  Click the "Get My Vibe" button to see your personalized result and recommendations.

## Technologies Used

*   **HTML5:** For structuring the web content.
*   **CSS3:** For modern, responsive, and visually appealing styling with a dark theme and vibrant blue accents.
*   **JavaScript (ES6+):** For handling quiz logic, score calculation, dynamic content generation, and personalized recommendations.
*   **Font Awesome:** For modern icons to enhance the user interface.
*   **Google Fonts (Poppins):** For a clean and contemporary typography.
